How to prepare a product CSV for supermarkets, minimarts and retail stores. Covers single products, variants, pack sizes, unit conversions and barcodes.

Preparation

Before you start

This guide is about the spreadsheet only — how to fill it, not how to upload it in the app. Give the completed CSV to your MartPoint admin.

Use CSV, not Excel

Work in Excel or Google Sheets, then Save As → CSV (Comma delimited) .csv. Uploading the .xlsx file will not work.

Keep the header row

Row 1 must contain the exact column names in the template. Do not delete, rename or rearrange them — extra columns are allowed to the right.

Parents before children

If you are importing variants, the parent row must come before the child rows that link to it. The child row uses the parent SKU.

Categories, brands and units are created automatically

If a category, brand, unit or tax name is not in the system yet, MartPoint will create it during import. Make sure the names are spelled the same every time.

Numbers: do not type currency symbols, thousands commas or words like "Naira". Use plain numbers: 1000.50. The import removes commas, but it is safer to avoid them.

Packaging and pricing

Selling units (Pack / Piece / Box)

Use selling units when customers can buy the same product in different pack sizes, for example one piece, a pack of 6, or a case of 24. Each pack can have its own barcode and price.

How it works

  • unit_name is the base/stock unit. Inventory is counted here.
  • selling_unit_1_unit is how the customer buys it (Pack, Box, Case).
  • selling_unit_1_conversion is how many base units are in that pack.
  • selling_unit_1_selling_price is the price for the whole pack.
  • selling_unit_1_barcode is what the cashier scans for that pack.
ColumnRequiredWhat to enterExample
selling_unit_N_unitYesName of the pack size. Change the number for each extra unit.Pack
selling_unit_N_conversionYesHow many base units are in this pack.6
selling_unit_N_selling_priceYesPrice to the customer for the pack.550
selling_unit_N_wholesale_priceNoWholesale price for the pack if you sell wholesale.500
selling_unit_N_purchase_priceNoYour cost for the pack. Leave blank to use the base cost.480
selling_unit_N_skuNoPack SKU.COKE-350-PACK
selling_unit_N_barcodeNoScannable barcode for the pack.BAR-COKE-PACK
selling_unit_N_defaultNoType 1 or Yes for the unit selected by default at POS. The first unit is default if none is set.1
Tip: If the base unit is Piece, set the piece as one selling unit with conversion 1 so the cashier can sell one piece or a pack by scanning the correct barcode.

Before sending the file, check this

  • Saved as .csv, not .xlsx
  • Header row is still the first row and is exactly as the template
  • Parent rows appear before their child rows
  • Numbers do not contain commas, currency symbols or words
  • SKUs are unique per store (do not duplicate)
  • Variant child rows have both parent_sku and variant_name
  • Dates use YYYY-MM-DD (e.g. 2026-12-31)
When the sheet is ready, send the CSV to your MartPoint admin. They will upload it through the Advanced Product Import screen.
