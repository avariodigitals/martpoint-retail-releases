Catalogue

The catalogue is your master product list. Search, filter, export, and edit prices from one place.

How to open

More → Inventory → Catalogue.

Screen fields

SearchProduct name or code
Category filterShow one category at a time
Brand filterFilter by brand
Stock statusIn stock, low, out of stock
Price columnsSelling price and cost
BarcodeGenerated or scanned code
ExportDownload as CSV or PDF
EditTap a product to update

Step-by-step

  1. Open Catalogue from the Inventory menu.
  2. Use the search box to find a product by name or code.
  3. Use category or brand filters to narrow the list.
  4. Tap a product to edit its details.
  5. Tap the price to update it directly (if allowed).
  6. Tap Export to download the price list for offline use.
Next: use Add Product to create new products, or Stock to view quantities.

Add Product

Create every product once and the system uses it for sales, purchases, and reports.

How to open

More → Inventory → Add Product.

Step-by-step

  1. Tap Add Product.
  2. Enter the product name and choose the category.
  3. Set cost price and selling price. The margin is used in profit reports.
  4. Enter opening stock and alert quantity.
  5. Add the barcode or SKU if you have one. MartPoint can also generate a barcode.
  6. Select the branch where stock is kept.
  7. Enable expiry tracking if the product has an expiry date.
  8. Tap Save. The product is now available in POS and sales.

Add Product with Variants

Variants let you sell one product in many options, such as a shirt in different sizes and colours. Each option gets its own stock count, barcode, and price, while the customer still sees it as one product.

Before you start: create attributes

Attributes are the options a product can have. Most fashion and retail stores create at least Size and Colour.

  1. Go to More → Inventory → Attributes.
  2. Tap New Attribute. Enter the name, for example Size.
  3. Add the values: Small, Medium, Large, XL.
  4. Create another attribute for Colour with values like Red, Blue, Black.
  5. Save each attribute.

Step-by-step: add a product with variants

  1. Go to More → Inventory → Add Product and fill in the normal product details: name, category, brand, unit, cost price, and base selling price.
  2. Scroll to the Variants section and turn on Has Variants.
  3. Pick the attributes this product needs, for example Size and Colour.
  4. Tap Generate Variants. MartPoint creates one row for every combination: Small Red, Small Blue, Medium Red, Medium Blue, and so on.
  5. For each row, enter:
    • Variant name — what staff see, e.g. "Classic Tee — Red, M"
    • SKU / Barcode — unique code for this option
    • Cost price — what you paid for this option (usually the same as the base product)
    • Selling price — set a different price if the option costs more, otherwise leave the base price
    • Opening stock — how many of this exact option you have
    • Alert quantity — when to warn you it is running low
  6. Choose the Branch where the stock is kept.
  7. Tap Save. The product and all its variants are now in the catalogue and ready for sale.

How it looks at the POS

When a cashier searches for the product, MartPoint shows the variant options. The cashier picks the right size and colour, then continues with payment as normal.

Search productType "Classic Tee"
Pick variantSelect Red, Medium
Stock checkSystem shows only Medium Red stock
SellProceed to payment and receipt
Tip: If two variants have different prices, set each variant's selling price. If they all cost the same, you can leave the base selling price and only set the variant names, barcodes, and stock.
